# Codveda Java Development Internship

This repository contains my Level 1 tasks for the Codveda Technology Java Development Internship.

## Level 1 – Basic Tasks

### Task 1: Basic Calculator
**Source file:** `Level-1/Calculator.java`

A Java console application that performs addition, subtraction, multiplication, and division. It accepts user input and handles division by zero.

**Concepts:** Java methods, conditional statements, user input, and exception handling.

### Task 2: Number Guessing Game
**Source file:** `Level-1/NumberGuessingGame.java`

A Java console game that generates a random number between 1 and 100. The user receives too-high or too-low hints and has a limited number of attempts.

**Concepts:** Random class, loops, conditional statements, and input validation.

## Technologies Used
- Java
- JDK
- Visual Studio Code

## How to Run

Open a terminal in the `Level-1` directory.

Run the Calculator:

```bash
javac Calculator.java
java Calculator
```

Run the Number Guessing Game:

```bash
javac NumberGuessingGame.java
java NumberGuessingGame
```
